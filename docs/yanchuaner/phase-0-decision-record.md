更新日期：2026-07-19
状态：`BLOCKED`（工程基线已登记，外部授权与运营决策尚未全部提供）

## 目的

阶段 0 只冻结身份、数据、版权、授权、部署和首批用户边界，不新增模型功能。它的结果不是“文件齐全”，而是任何进入阶段 1 的决定都有责任人、证据和回滚动作。

本文件是燕中 API 控制面的阶段 0 真值登记。AI 工作台的补充门禁见 `ai_yanchuaner/docs/phase-0-gate.md`；生态总览见主站仓库中的《燕中生态项目关系》。

## 阶段 0 交付物

- 一份由运营主体批准的 D-01 至 D-08 决策记录；
- 主站、API、AI 三套用户条款/隐私声明的字段和版本对应关系；
- Open WebUI 和模型供应商许可证据编号；
- 生产域名、证书、Secret、备份和管理员权限清单；
- 首批用户范围、支持方式和退出机制；
- 证据库索引（文件名、负责人、创建日期、SHA-256），但不公开敏感原件。

## 阶段 0 退出条件

只有以下条件全部满足，才能把状态从 `BLOCKED` 改为 `READY_FOR_PHASE_1`：

1. D-01 至 D-08 均有负责人、批准日期和证据编号；
2. Open WebUI 品牌策略与模型供应商授权可被复核；
3. 首批用户仅能通过主站身份进入，停用和删除路径已演练；
4. 生产 Secret、备份和管理员权限不依赖个人工作站；
5. API、AI、主站镜像和根目录生态文档的状态与决策编号一致；
6. 运营负责人明确批准阶段 1 的范围、预算上限和停止条件。

## 回滚与暂停

阶段 0 的回滚不是删除文档，而是将发布状态降回 `BLOCKED`：停止新用户、停止新 Key 和模型调用，保留审计与只读数据；撤销未经批准的品牌配置、供应商渠道和管理员权限。任何证据失效、主体变更、供应商条款变化或数据泄露都自动触发暂停复核。

本文件是工程治理记录，不是法律意见，也不替代运营主体、权利人或法律顾问的正式批准。
